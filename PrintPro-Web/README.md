# PrintPro Web — browser counter

Open `index.html` in Chrome or Edge (double-click). No install, no server.

- Same rules as the Java program: 10% student / 15% faculty discount, 18% GST on the discounted amount,
  daily capacity checks (a rejected job changes nothing), JOB1/JOB2 ids, odd token -> Tray 1, even -> Tray 2.
- Shortcuts match the console: Service ID `-1` = undo last, `0` = finish and bill.
- "Run test cases" checks cases 1-4 on a separate fresh shop.
- Today's jobs are kept in this browser; "Close the day" in the report resets them.
- Fonts load from Google Fonts when online; offline it falls back to system fonts.
